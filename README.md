# Simple Interest Calculator

This project is a simple interest calculator written in Bash.

## Description
The calculator helps users calculate simple interest
based on the principal amount, annual interest rate,
and time period.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

## How It Works
1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. The calculator displays the simple interest.
